## SDK Reality Check

| Integration | Python | Node |
|---|---|---|
| **Genblaze** | ✅ Python-only SDK (monorepo, `pip install genblaze`) | ❌ None |
| **Qwen / DashScope** | ✅ Official `dashscope` SDK (v1.26.0 on PyPI) | ⚠️ Community-only, unmaintained |
| **Qwen via OpenAI-compat** | ✅ `openai` Python SDK works (v2.44.0) | ✅ Works too |
| **CockroachDB** | ✅ `psycopg2` / `asyncpg` (PostgreSQL-compatible) | ✅ `pg` works |
| **Backblaze B2** | ✅ `b2sdk` official Python SDK | ⚠️ Third-party only |

Genblaze being **Python-only** is the deciding factor. You'd be fighting the framework the entire hackathon if you used Node.

## Recommended Stack

```
Python 3.11+
├── genblaze          # media pipeline orchestration + B2 storage
├── dashscope         # Qwen video/image/audio generation (official)
├── openai            # fallback OpenAI-compat calls to Qwen
├── asyncpg           # async CockroachDB connection (faster than psycopg2)
├── pgvector          # vector similarity for character embeddings  
├── fastapi           # lightweight API layer
├── celery + redis    # async task queue for video generation jobs
└── boto3             # direct B2/S3 access when needed outside genblaze
```
